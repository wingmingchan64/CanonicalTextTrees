# 馬太受難曲生成流程

Status: Stable

此文檔解釋 <a href="https://github.com/wingmingchan64/CanonicalTextTrees/blob/main/corpus/others/bach_cantatas/views/244_dic.json">244_dic.json</a> 一文檔的生成流程。

---

## 整理詞典

- 下載 dict.cc、IPA 等相關文檔，以程式處理、生成 JSON 格式的詞典

<pre>
    "Einbaurichtung": "mounting direction",
    "Einbausatz": "installation kit",
</pre>

- 手編 Cambridge、Langenscheidt、Google 等資料

---

## 整理德語原文、英語譯文之正文

- <a href="https://github.com/wingmingchan64/CanonicalTextTrees/blob/main/corpus/others/bach_cantatas/canonical_text/244_DE.txt">德語原文</a>、<a href="https://github.com/wingmingchan64/CanonicalTextTrees/blob/main/corpus/others/bach_cantatas/canonical_text/244_EN1.txt">英語譯文</a>分別儲存於兩個不同文檔，但兩文檔格式（行數、空行位置、分段、分行）完全一樣；這樣就不用另編後設資料來聯係二者

## 生成資料樹

- <a href="https://github.com/wingmingchan64/CanonicalTextTrees/blob/main/tools/php/bin/bach_cantatas/%E7%94%9F%E6%88%90%E5%BE%B7%E8%AA%9E%E6%AD%A3%E6%96%87%E6%A8%B9%E3%80%81%E8%A9%9E%E5%85%B8.php">生成德語正文樹、詞典.php</a>
