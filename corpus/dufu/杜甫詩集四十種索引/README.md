## 說明

黃永武主編的《杜甫詩集四十種索引》，是架在系統與杜著述之間的、一條理想的橋梁。有了這個索引，從系統的默認文檔碼出發，在這些杜著述中找相對應的篇章，會變得比較容易。不過，這個索引所用的書，不一定是最好的版本。在我的目錄/索引中，會盡量多提供不同版本的資料。

---

## 校記

- 頁六三：置於十一畫下的「晨雨」誤作「農雨」。
- 頁九八：「暝」誤作「瞑」。
- 頁一〇四：「營屋」誤作「螢屋」；又當移置於十七畫下。
- 頁一一一（第三條）：「歸燕」誤作「歸雁」。
- 頁一一六：《夔府書懷四十韻》重複。
- 頁一一六：《續得觀書迎就當陽居止正月中旬定出三峽》「續」誤作「繽」。
