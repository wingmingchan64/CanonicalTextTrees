# 杜著述

## 文件夾結構

<pre>
- 著述書名
  - canonical_text （杜著述文本）
  - coordinates （杜著述文本內容、路徑）
  - metadata （後設資料）
    - 文檔碼
	  - m_tree.json
	  - 夾注.txt
	  - 旁注.txt
	  - 注釋.txt
	  - 異文.txt
	  - 眉批.txt
	  - 評論.txt
	  - 題注.txt
	  - 題解.txt
	- trees
	- views （面貌文檔樣本）
</pre>

## 後設資料標記規則

> `{"scope":"0042,6,1,2","src_path":"JINGQUAN,0001,8"}`

- "scope": 基準正文樹路徑，可用格式：
  - a              （樹錨名）
  - 0003           （默文檔碼）
  - 0003,詩題       （默文檔碼,詩題）
  - 0013,1         （組詩： 默文檔碼,首碼）
  - 0003,3         （默文檔碼,行碼）
  - 0013,1,5       （組詩： 默文檔碼,首碼,行碼）
  - 0003,3,1       （默文檔碼,行碼,句碼）
  - 0013,1,5,2     （默文檔碼,首碼,行碼,句碼）
  - 0003,3,1,2     （默文檔碼,行碼,句碼,字碼）
  - 0003,3,1,1-3   （默文檔碼,行碼,句碼,範圍字碼）
  - 0013,1,5,2,2   （默文檔碼,首碼,行碼,句碼,字碼）
  - 0013,1,5,2,1-3 （默文檔碼,首碼,行碼,句碼,範圍字碼）
  - 只有字碼可用範圍標記
- "scope": 在該文檔中只出現一次的詩文片段
